# 🎴 Yu-Gi-Oh! OCG Series 1 Encyclopedia (1999–2000)

Ensiklopedia web interaktif dan komprehensif untuk **Yu-Gi-Oh! Official Card Game (OCG) Series 1**, era fondasi permainan kartu Yu-Gi-Oh! yang dirilis di Jepang antara **Februari 1999 hingga Maret 2000**.

Proyek ini mendokumentasikan secara presisi seluruh **717 kartu unik debut** yang pertama kali dicetak dalam sejarah Yu-Gi-Oh!, lengkap dengan visual resolusi tinggi, statistik resmi Konami, 27 set/rilis bersejarah, 7 deck meta kompetitif, dan 12 sinergi kartu.

## ✨ Fitur Utama

- 🔍 **Pencarian Global Instan:** Cari dari 717 kartu berdasarkan nama kartu, tipe (Normal Monster, Effect Monster, Fusion Monster, Ritual Monster, Spell, Trap), atribut (LIGHT, DARK, FIRE, WATER, EARTH, WIND), atau level bintang.
- 📦 **27 Rilis Bersejarah:**
  - **7 Volume Reguler:** Vol.1 (Feb 1999) hingga Vol.7 (Maret 2000).
  - **7 Booster Carddass:** Mesin vending Bandai Carddass (Booster 1–7).
  - **3 Starter Box:** Theatrical Release, Retail Release, dan EX Starter Box.
  - **10 Special & Promo Releases:** Termasuk Limited Edition 1, Premium Pack 1 & 2, Dark Ceremony Edition, turnamen Tokyo Dome, buku panduan Shueisha, dan hadiah game Nintendo Game Boy / PS1.
- ⚔️ **7 Deck Meta Klasik (Lengkap dengan Decklist):**
  1. *Silver Fang Beatdown* (Era Vol.1 — Beast Fangs Aggro)
  2. *Summoned Skull Beatdown* (Era Vol.4 — 2500 ATK 1-Tribute Boss)
  3. *Exodia Stall & Draw* (Format Slow Control Win-Condition)
  4. *Black Skull Dragon Turbo* (Fusion Apex 3200 ATK)
  5. *Dark Magician Beatdown* (Spellcaster Dominance)
  6. *Black Luster Ritual Beatdown* (Akhir Series 1 — Dark Ceremony Edition)
  7. *Kaiba Dragon Flute Turbo* (Lord of D. + Flute of Summoning Dragon)
- 🔗 **12 Sinergi Kartu:** Panduan interaktif keterkaitan antar kartu klasik (Dark Magician & Magical Mist, Dragon Beatdown, Cocoon of Evolution, Time Wizard Gamble, Fusion Rush, Burn & Stall, dll).
- 🎨 **Estetika Premium & Responsif:** Dark mode elegan bertema Millenium Puzzle emas, efek kartu melayang 3D di Hero, partikel dinamis, modal detail kartu pop-up, dan filter set instan.

## 🛠️ Teknologi

- **HTML5:** Struktur semantik modular.
- **Vanilla CSS3:** Custom Design System, Flexbox/Grid, Glasmorfisme, Animasi Keyframes 3D, tanpa dependensi framework berat.
- **Modern JavaScript (ES6+):** Pure Vanilla JS untuk rendering data reaktif, pencarian cepat, modal controller, dan animasi counter.
- **Data Source:** Yugipedia MediaWiki API & Konami Official Card Database via YGOPRODeck API.

## 🚀 Cara Menjalankan Secara Lokal

Cukup jalankan server web statis sederhana di root direktori:

```bash
# Menggunakan Node.js built-in HTTP server:
npx serve .

# Atau menggunakan Python:
python -m http.server 8080
```

Buka peramban (browser) di: `http://localhost:8080/`
